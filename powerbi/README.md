# Power BI Business Intelligence Architecture & Implementation Guide

## 1. Connecting Power BI Desktop

Power BI can be populated using two flexible connection modes:

### Option A: Direct PostgreSQL Connection (Recommended for Enterprise Setup)
1. Open **Power BI Desktop**.
2. Click **Get Data** -> **PostgreSQL database**.
3. Server: `localhost:5432` | Database: `olist_analytics`.
4. Select Data Connectivity Mode: **Import** or **DirectQuery**.
5. In Navigator, check the tables under the `analytics` schema:
   - `analytics.dim_date`
   - `analytics.dim_customer`
   - `analytics.dim_product`
   - `analytics.dim_seller`
   - `analytics.dim_location`
   - `analytics.fact_orders`
   - `analytics.fact_sales`
   - `analytics.fact_payments`
   - `analytics.fact_reviews`

### Option B: High-Speed Processed CSV Import
1. In Power BI Desktop, click **Get Data** -> **Text/CSV** or **Folder**.
2. Browse to `data/processed/` and select all 9 processed CSV files generated by `src/pipeline.py`.

## 2. Power BI Data Model (Star Schema Relationships)

| From (Fact) | Foreign Key | To (Dimension) | Primary Key | Cardinality | Cross Filter Direction |
|---|---|---|---|---|---|
| `fact_sales` | `date_key` | `dim_date` | `date_key` | Many to One (*:1) | Single |
| `fact_sales` | `customer_key` | `dim_customer` | `customer_key` | Many to One (*:1) | Single |
| `fact_sales` | `product_key` | `dim_product` | `product_key` | Many to One (*:1) | Single |
| `fact_sales` | `seller_key` | `dim_seller` | `seller_key` | Many to One (*:1) | Single |
| `fact_orders` | `purchase_date_key` | `dim_date` | `date_key` | Many to One (*:1) | Single |
| `fact_orders` | `customer_key` | `dim_customer` | `customer_key` | Many to One (*:1) | Single |
| `fact_payments` | `date_key` | `dim_date` | `date_key` | Many to One (*:1) | Single |
| `fact_reviews` | `date_key` | `dim_date` | `date_key` | Many to One (*:1) | Single |
| `fact_orders` | `order_id` | `fact_payments` | `order_id` | One to Many (1:*) | Both / Single |
| `fact_orders` | `order_id` | `fact_reviews` | `order_id` | One to Many (1:*) | Both / Single |
